# Проект «Композиция»

Перед изменением поведения сверяться с исходным ТЗ Figma и документами `docs/SOLUTION_PLAN.md`, `docs/TEST_MATRIX.md`, `docs/RESEARCH.md`. В общей рабочей папке первичные согласованные документы находятся в `../planning/`; копии `docs/` синхронизируются перед выпуском.

Исходник: https://www.figma.com/design/4MCFttsSoP7hgQh29zq5G3/?node-id=26-11438 . Страницы: «Задание», «Библиотека компонентов», «Примеры композиций».

- Использовать только исходные векторные иллюстрации, не подменять их значками или растром.
- Сохранять геометрию и относительные пропорции объектов, роли main/background, варианты S/L и правила палитры.
- Экспорт обязан быть самостоятельным и редактируемым SVG.
- Новые операции проходят через модель сцены; исходный каталог не изменяется при редактировании.
- Для каждого этапа обновлять `docs/IMPLEMENTATION_LOG.md` и доступный первичный `../planning/IMPLEMENTATION_LOG.md`; для проверок записывать реальные результаты, не предположения.
- Без явного запроса не менять согласованный объём и не заменять требования упрощёнными имитациями.
