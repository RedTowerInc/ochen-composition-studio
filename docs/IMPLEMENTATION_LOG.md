# Ход реализации

Основания: исходное ТЗ Figma, SOLUTION_PLAN.md, TEST_MATRIX.md и RESEARCH.md. Срок: два дня. Интерфейс: согласованный вариант «Студия».

## Этап 1 — исходная библиотека и экспорт

Статус: завершён.

- Согласованный стек сохранён: React + TypeScript + Vite + нативный SVG.
- Создан отдельный каталог приложения `app`.
- Зависимости установлены; npm сообщил 0 известных уязвимостей на момент установки.
- Получена пользовательская копия Figma `pnpYBt06NCRv8gnkQXrjYD`; тексты всех трёх страниц повторно прочитаны через официальный инструмент.
- Подтверждены 10 семейств: книга, телефон, пазлы, наушники, лампа, кошелёк, ручка, папка, монета, ваза с цветами. Ранее визуальные догадки о часах и блокнотах исключены из реализации.
- После пяти отдельных SVG исчерпан лимит Figma MCP Starter. Через штатный экспорт Chrome получены оба полных векторных листа L/S; оригиналы сохранены в `app/catalog-source/`.
- Выделены 40 исходных групп, выгружены три реальные палитры, записаны sourceNodeId и SHA-256. Все цвета входят в объявленные роли; у фоновых объектов нет объектных цветов.
- Подтверждены сохранение path при очистке/перекраске, уникальность внутренних id и самостоятельность экспорта.

## Этап 2 — ядро и интерфейс

Завершены: React-интерфейс «Студия», команды сцены, Undo/Redo, три шаблона с оценкой восьми кандидатов каждый, смысловой словарь и точный ввод объектов, импорт палитры/проекта, экспорт SVG, очередь IndexedDB с транзакционным сравнением версий. Фоновые объекты включаются по выбору пользователя. Относительные размеры сохраняет общий масштаб набора (L: 1, S: 2), без отдельного нормирования предметов.

Исправлены найденные проверками проблемы: лишняя запись при открытии сохранённого проекта второй вкладкой; накопительное уменьшение при круговой смене форматов; HTML-entities при подготовке XML; сравнение палитр по порядку JSON-ключей; сохранение пробела при вводе названия. Неактуальные задачи и импорты отбрасываются.

## Этап 3 — проверка и комплект

Завершены: 22 теста ядра, 38 сценариев Chromium/Firefox, 1000 случайных последовательностей до 100 команд (seed 20261110), 100 перекрывающихся задач, десять независимых посетителей, две конкурирующие вкладки, отказы/upgrade IndexedDB, pointercancel/blur, обратный порядок импорта, предел 50 объектов. Production прошёл пиксельное сравнение предпросмотра/экспорта в трёх форматах и 20 циклов S/L/палитр без изменения SVG.

Три примера открыты в независимом SVG-edit; изменена координата узла проверочной копии и выполнено повторное открытие. Короткий замер: 50 объектов, p95 экспорта 53.7 мс; сборка трёх вариантов p95 0.9 мс. Подробные границы и результаты: `app/TEST_REPORT.md`.

Подготовлены README, архитектура, список AI-инструментов, три SVG+JSON-примера, видео и запуск готовой сборки без npm-зависимостей. Формат выпуска — приватный GitHub и приватная веб-версия. Итоговые URL, commit и сведения о публикации фиксируются в `release.json` комплекта сдачи; перед передачей работодателю потребуется предоставить доступ.
