# Реестр строгой приёмки 0.1.1

Дата: 11 ноября 2026, Томск. Статус: программная приёмка и локальная поставка пройдены в указанном окружении; ограничения ниже сохраняются. Идентификация и фактическая проверка конкретной публикации находятся в release.json комплекта 0.1.1.

Исходная версия: `1d4c23eef2e2459ed99285a54c6887566dd10bf3`. Исправленный продукт: fingerprint 70 файлов `66c42d1aad6fbf85ef2b0ca596b34f3f7ba850b1b12e2c8f72b675319efeae7e`; алгоритм и файлы — `verification/source-fingerprint.json`. Commit и SHA архивов фиксируются после упаковки. Документация и QA-артефакты не входят в fingerprint продукта.

Fingerprint побайтовый и относится к поставляемым исходникам. Git может преобразовать переводы строк при checkout; такое преобразование меняет побайтовый fingerprint. Воспроизводимость результата проверена отдельно по SHA-256 всех 51 файлов dist после чистого npm ci и build.

Группы не означают перебор всех возможных входов. Точное численное покрытие находится в JSON. Alpha-анализ выполнен на фиксированной выборке, а не на всех геометрических наборах. Исходные 40 SVG не изменены; source-comparison.json и catalog unit подтверждают геометрию и SHA.

Серверный AI, серверные межпользовательские транзакции и полноценный языковой анализ неприменимы к согласованному локальному приложению. WebKit/другие ОС/физический touch не проверены; эти платформы не заявляются. Настоящий Chrome zoom проверен отдельно от viewport-эмуляции.

## Ошибки стенда

- Локатор прежней кнопки палитры обновлён под ясную подпись «Загрузить JSON-палитру».
- Прежняя отмена сборки не останавливала часы: пропуск 45-мс окна не является ошибкой программы. Часы теперь остановлены явно.
- Десять посетителей создают 400 загрузок/проверок SVG на одном компьютере. Прежних 7 секунд было недостаточно; production укладывается в 20-секундное ожидание. Это изоляция, не нагрузочный тест хостинга.
- Состав сравнивается как мультимножество: порядок слоёв разрешено менять, одинаковые семьи не схлопываются.
- Неверный локатор поворота сначала исправлен; последующий прогон отдельно воспроизвёл реальный дефект отмены. После исправления проверка прошла в обоих браузерах.
- Firefox при эмуляции обычного ввода сам удалял U+0001: нельзя ожидать XML-ошибку для отсутствующего символа. Проверка теперь явно устанавливает точное значение через DOM input event и до Enter проверяет наличие символа; отказ приложения подтверждён отдельно.
- Нет ожидаемых падений, skip или автоматических retries. Предыдущие неудачные результаты и причины сохранены.
