# Доказательства исправлений

В репозиторий входят исходники проверок, структурированные JSON-результаты, замороженный baseline, причины исходных падений, численные измерения и итоговые изображения. Baseline не заменён успешным прогоном.

Объёмные HTML-отчёты с приложенными trace.zip и исходниками SVG сохранены в локальной рабочей папке, но исключены из Git и выдаваемого рабочего архива. Их можно заново получить командами из `docs/REMEDIATION_TESTS.md`; ошибки сохраняют trace и screenshot, автоматических retry нет. Это сокращение размера комплекта, не удаление неудачных результатов: JSON исходных падений и пояснения остаются в истории.

`baseline-final-2026-11-10` — принятый исходный baseline. Предварительные `baseline-*` со сломанными тестовыми часами исключены из приёмки. `rotation-before-fix` — неверный локатор теста; `rotation-before-fix-verified` — воспроизведённый дефект программы. `ui-first-attempt` использовал искусственный pointerdown вне видимой области и не доказывает ошибку drag; окончательный `ui-final` использует настоящий mouse input по видимой нарисованной точке.

Окончательные доказательства и пределы утверждений перечислены в `TEST_REPORT.md` и `docs/REMEDIATION_ACCEPTANCE.md`.
