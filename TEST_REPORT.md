# Отчёт о проверках

Дата: 10 ноября 2026. Блокирующих ошибок в проверенной версии нет. Ограничения: смысловой подбор работает по явному словарю, проекты хранятся локально, совместного редактирования одной сцены и серверного AI нет. WebKit, нативный zoom браузера 125/200% и 30-минутный замер памяти отдельно не проверялись. Точный commit опубликованного исходника записан в release.json рядом с архивом; состав исходников зафиксирован в verification/source-fingerprint.json.

## Окружение и команды

Windows, Node.js 24.16.0, Intel Core i5-10500H 2.50 GHz, 12 логических потоков. Chromium: установленный Chrome 157; Firefox: Playwright Firefox 159. Версии зависимостей закреплены package-lock.json.

SVG-edit импортирует через публичный loadFromString API; проверка редактирования использует его панели координат узла. Это не проверка системного диалога выбора файла SVG-edit. Оригинальные примеры не изменялись: для редактирования создана отдельная проверочная копия.

При одном совместном запуске CPU-нагрузки и аудита каталога первоначальный 5-секундный timeout теста каталога оказался слишком коротким. Для полного аудита 40 файлов установлен отдельный лимит 20 секунд; повторный запуск прошёл. Это лимит стендового теста, не изменение требований к производительности приложения.

## Короткий замер производительности

25 экспортов на каждое число объектов, всего 100; браузерный SVG DOM и настоящие исходники. Время — синхронная подготовка файла, без системного сохранения и сетевой загрузки страницы.

| Объекты | p95 экспорта | Максимум |     Размер SVG |
| ------- | -----------: | -------: | -------------: |
| 1       |       1.2 мс |   1.9 мс |    29 618 байт |
| 10      |      13.6 мс |  18.6 мс |  389 273 байта |
| 25      |      28.8 мс |  37.0 мс |   976 275 байт |
| 50      |      53.7 мс |  59.1 мс | 1 948 521 байт |

Сборка трёх вариантов с оценкой 24 кандидатов: 100 запусков, p95 0.9 мс, максимум 4.4 мс. Это измерение ядра; видимая UI-сборка дополнительно уступает кадр браузеру и рисует SVG. Цели плана 500 мс для сборки и 1000 мс для экспорта на этом стенде выполнены. Числа не гарантируют такую же скорость на любом устройстве.
