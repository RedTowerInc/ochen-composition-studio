# Композиция — векторная студия

Веб-редактор для тестового задания «Студии Очень»: заголовок или список объектов → три варианта композиции → ручная доводка → самостоятельный SVG.

Используются только оригинальные иллюстрации работодателя: 10 семейств, цветная и фоновая роли, настоящие варианты S/L — всего 40 SVG. Новые иллюстративные объекты не генерируются.

## Запуск

Нужен Node.js 24.15+ из ветки 24 LTS либо Node.js 26+.

```sh
npm ci
npm run dev
```

Откройте адрес Vite, обычно http://127.0.0.1:5173. Для production: `npm run build`, затем `npm run preview`. Каталог и шрифт включены в проект; ключи API и сервер базы данных не нужны.

Если получен готовый архив с `dist/`, достаточно Node.js и команды `node scripts/serve-preview.mjs` (Windows: `start-studio.cmd`). Зависимости для готовой сборки устанавливать не нужно. Адрес — http://127.0.0.1:4173.

Исходники: [GitHub](https://github.com/RedTowerInc/ochen-composition-studio). Репозиторий создан приватным; перед передачей работодателю владелец предоставляет доступ.

Веб-версия с доступом владельца: [Композиция](https://ochen-composition-studio-andy.andymoorenkz.chatgpt.site). В комплекте выпуска есть `release.json` с подтверждённой версией и commit.

## Что можно сделать

- Подобрать объекты по темам: фокус, учёба, идеи, работа, связь, отдых, финансы. Неизвестный смысл требует уточнения; сервис не обещает понимание любого заголовка.
- Перечислить точные названия через запятую: `Книга, Наушники, Лампа`. Доступны также телефон, пазлы, кошелёк, ручка, папка, монета и цветы. Английские идентификаторы каталога тоже принимаются.
- Получить варианты трёх композиционных схем. Общий масштаб рассчитывается по всему набору; поиск ограничен 120 попытками. Непригодные варианты отбрасываются, при необходимости используется вписывание в сетку. Фоновые объекты можно отключить.
- Перемещать, поворачивать, дублировать, удалять объекты и менять порядок слоёв. Индивидуального растягивания нет: относительные размеры сохраняются.
- Менять формат, S/L, роль объекта и палитру; загрузить собственную палитру по образцу JSON.
- Скачать SVG или файл проекта, восстановить проект из JSON. Отмена: Ctrl/Cmd+Z, повтор: Ctrl/Cmd+Shift+Z, дубликат: Ctrl/Cmd+D, удаление: Delete, сдвиг: стрелки; Shift увеличивает шаг.

Название подтверждается Enter или выходом из поля; Escape отменяет черновик. На узком экране отмена и повтор доступны в меню «Проект».

Палитра содержит восемь именованных ролей. Нейтральные `ink` и `paper` сохраняются. Значения объектных ролей не совпадают с фоновыми. Неполная/некорректная палитра отклоняется целиком.

## Сохранение и параллельная работа

Проекты хранятся в IndexedDB этого браузерного профиля. Разные профили/посетители изолированы. Две вкладки одного проекта используют транзакционное сравнение версий: конфликт не перезаписывает чужую запись, своя версия остаётся в памяти. Доступны сохранение отдельной копии, открытие актуальной версии и скачивание JSON.

Меню «Проект» → «Открыть сохранённый проект» возвращает к прежним работам. Выбор запоминается отдельно для вкладки. Перед созданием или открытием другого проекта редактор ожидает подтверждения актуальной записи; при отказе оставляет сцену открытой и предлагает сохранить JSON. Выбор уже открытого проекта сохраняет текущие правки.

Это локальный редактор, без аккаунтов и совместного редактирования одной сцены в реальном времени. Люди с общим браузерным профилем имеют общее локальное хранилище. При отказе хранилища работа и экспорт продолжаются. Статус «Сохранено» появляется после commit; принудительное закрытие до commit может потерять последнюю правку. Для переноса и резервной копии используйте файл проекта.

## Проверки

```sh
npm run typecheck
npm test
npx playwright install firefox
npm run dev
# В другом терминале; Chromium-проверки используют установленный Google Chrome:
npm run test:e2e
```

Точные результаты, окружение, ограничения и соответствие матрице: [TEST_REPORT.md](TEST_REPORT.md). Архитектура: [ARCHITECTURE.md](ARCHITECTURE.md). Использование AI: [AI_TOOLS.md](AI_TOOLS.md).

Для новых строгих регрессий сначала выполните `npm run build`, затем `npx vitest run --config vitest.regression.config.ts` и `npx playwright test --config playwright.regression.config.ts`. Последняя команда сама запускает статическую сборку; порт 4173 должен быть свободен. В PowerShell другой порт задаётся через `$env:OCHEN_TEST_PORT='4174'`. Матрица и критерии — в `docs/REMEDIATION_TESTS.md`.

Лимиты первой версии: 50 объектов вручную, 6 в автосборке; сторона холста 128–4096 px; ввод 1000 символов; палитра 32 KiB; проект 2 MiB; история 60 состояний. Офлайн после загрузки работают смысловой словарь, редактирование и SVG-экспорт. Первая загрузка требует доступного приложения; service worker не используется.

## Происхождение библиотеки

[Исходное задание](https://www.figma.com/design/4MCFttsSoP7hgQh29zq5G3/?node-id=26-11438). Из пользовательской копии выгружены штатным экспортом два оригинальных векторных листа. Они сохранены в `catalog-source/library-L.svg` и `library-S.svg`. Подготовка выделяет существующие группы, сохраняет пути и необходимые defs, добавляет только SVG-контейнер. Размеры объектов не выравниваются по отдельности. `catalog-source/audit.json` содержит sourceNodeId, SHA-256, число узлов и использованные цвета каждого файла.

Библиотека работодателя включена для выполнения тестового задания. Шрифт Manrope распространяется по OFL, лицензия лежит в `public/fonts/OFL.txt`.
